# BrainAid Agent Architect

**Скилл для Claude Code и Codex: проектирует AI-агентов, проверяет архитектуру и помогает исправлять подтверждённые проблемы.** В комплекте — офлайн-скрипты анализа кода, проверки графов и лаборатория синтетических отказов.

[English README](README.md) · [BrainAid AI News](https://t.me/BrainNeuroassistant) · [Сайт](https://brainaid.ru)

> **Важное ограничение:** скилл не гарантирует безошибочность произвольного проекта и не следит за production в реальном времени. Встроенные инструменты проверяют локальные файлы и запускают безопасные имитации отказов. Реальные API, деплой, платежи и публикации сами по себе не тестируются.

## Зачем он нужен

- **DESIGN** — превращает описание задачи в спецификацию графа: узлы, типизированное состояние, условия переходов, границы стоимости, сроки, обработка отказов, человек в контуре.
- **AUDIT** — изучает существующий проект без изменений, ищет потенциальные бесконечные циклы, неустойчивые retry, потерю состояния, дубли действий и уязвимые согласования. Указывает файл, строку, уверенность и сценарий сбоя.
- **HARDEN** — по **явному запросу** исправляет проблемы в коде, добавляет тесты, показывает реальные команды, результаты и неустранённые риски.

Подходит для Telegram-ботов, CRM, AI-саппорта, контент-автоматизаций, аналитики и агентных приложений на LangGraph/CrewAI/AutoGen. Скилл не привязан к одной модели или одному фреймворку.

## Установка: Windows 10/11, Claude Code и Codex

Нужен **Python 3.10+** только для установщика и локальных проверок; сам `SKILL.md` читается агентами и без Python.

1. Скачайте ZIP проекта и распакуйте папку `brainaid-agent-architect`.
2. Откройте PowerShell **внутри этой папки**, рядом с `SKILL.md`.
3. Выполните команду:

```powershell
py -3 install_skill.py --target both --scope user
```

Если в системе Python вызывается командой `python`:

```powershell
python install_skill.py --target both --scope user
```

Установка **только для одного проекта**:

```powershell
python install_skill.py --target both --scope project --project "C:\path\to\my-project"
```

Проверка без изменений:

```powershell
python install_skill.py --target both --scope user --dry-run
```

Повторная установка при уже установленном скилле:

```powershell
python install_skill.py --target both --scope user --force
```

`--force` сохраняет старую копию в папке с временной меткой, затем устанавливает новую. Без `--force` существующий скилл **не перезаписывается**. После установки начните новую сессию Claude Code / Codex.

Пути установки:
- Claude Code: `%USERPROFILE%\.claude\skills\brainaid-agent-architect`
- Codex: `%USERPROFILE%\.agents\skills\brainaid-agent-architect`

Можно вызывать явно: `/brainaid-agent-architect` в Claude Code или `$brainaid-agent-architect` в Codex (если ваша версия поддерживает явный вызов) либо написать «Используй скилл brainaid-agent-architect».

## Первые запросы

**Аудит без изменения кода:**

```text
Используй brainaid-agent-architect в режиме AUDIT. Проверь текущий проект
на неконтролируемые циклы, потерю состояния, повторные внешние действия,
ошибки API и небезопасное согласование. Не меняй файлы. Укажи файл:строку
для каждого вывода, отличай факт от гипотезы и предложи тесты.
```

**Создание архитектуры:**

```text
Используй brainaid-agent-architect в режиме DESIGN. Разработай AI-саппорт
в Telegram с базой знаний и передачей платежных споров оператору.
Нужны схема Mermaid, состояние, узлы, лимиты, сохранение, идемпотентность
и план тестов. Код пока не пиши.
```

**Исправление:**

```text
Используй brainaid-agent-architect в режиме HARDEN. Исправь найденное
дублирование операций при повторном webhook, добавь тест и покажи
результаты запуска. Продакшен не трогай.
```

## Локальные команды

В папке скилла:

```powershell
python scripts/doctor.py
python scripts/validate_spec.py examples/content_pipeline.json
python scripts/audit_project.py fixtures --format markdown
python scripts/fault_lab.py --all
python -m unittest discover -s tests -v
```

| Инструмент | Что делает | Ограничение |
|---|---|---|
| `doctor.py` | Проверяет комплектность установки и метаданные | Не проверяет запуск внутри самого Claude/Codex |
| `validate_spec.py` | Проверяет JSON-описание графа, достижимость, циклы и лимиты | Не проверяет фактический рантайм |
| `audit_project.py` | Эвристический AST-аудит Python (без исполнения кода) | Не видит всю динамику, JS/TS и импортируемые графы |
| `fault_lab.py` | Демонстрирует 12 сценариев отказов на локальных заглушках | Не тестирует реальный Telegram/API/проект пользователя |

Все скрипты работают на стандартной библиотеке Python, без токенов, платных API и доступа в сеть. Лаборатория использует временную SQLite-базу, не трогая чужой проект.

## Что конкретно проверяет подход

- Максимальное количество генераций и общий бюджет графа.
- Отдельные технические повторы при 429/5xx.
- Хранение состояния и восстановление после перезапуска.
- Версионированное подтверждение действий человеком.
- Защиту от повторного webhook и неоднозначной отправки.
- Разделение программных проверок, фактчекинга и LLM-оценки.
- Ограничение прав агентов и недоверенные входные данные.
- Метрики, трассировку и реальные тесты вместо слов «готово».

**Скилл — инженерный помощник, а не сертификат безопасности.** Чтобы подтвердить надёжность реального бота, нужны отдельные интеграционные тесты с его API и хранилищем на тестовом стенде.

## Проект и лицензия

- `SKILL.md` — правила проектирования, аудита и усиления.

- `references/` — архитектурные паттерны и практики.
- `tests/` и `fixtures/` — автотесты и учебный дефектный проект.
- `.github/workflows/tests.yml` — CI для Windows и Linux.
- `SECURITY.md` и `CONTRIBUTING.md` — безопасность и правила участия.
